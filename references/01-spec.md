# 01 · 严格规范（Spec）

> 关键词约定：**必须（MUST）** = 不满足即不合格；**应该（SHOULD）** = 默认遵守，有理由可偏离；**可以（MAY）** = 可选。
> 适用对象：人工制作者与 AI（Claude、Codex、WorkBuddy、Trae、飞书 Aily 等）。

---

## 1. 文件与交付

| 编号 | 规则 | 级别 |
|---|---|---|
| F1 | 交付物是**一个独立的 `.html` 文件**，双击即可在 Chrome / Edge / Safari 打开。 | 必须 |
| F2 | 以 `template/deck-template.html` 为母版。只增删 `<section class="slide">`，**不改引擎 CSS 与 JS**（主题 token 除外）。 | 必须 |
| F3 | 图片以 base64 内嵌，单张宽 ≤ 1400px、体积 ≤ 250KB；整个文件 SHOULD ≤ 15MB。 | 必须 |
| F4 | **不内嵌视频**。需要动态效果时，用页面内 CSS / SVG 动画（≤ 3 秒，可被翻页跳过）。 | 必须 |
| F5 | 外部资源只允许 Google Fonts；字体栈必须带本地后备字体（见 03-themes.md）。 | 必须 |
| F6 | 需要外部图片文件时，放在与 HTML 同级的 `assets/` 文件夹，并在页面上给出“截图位”占位说明。 | 可以 |

## 2. 画布与版面

| 编号 | 规则 | 级别 |
|---|---|---|
| L1 | 画布固定 **1600 × 900**，引擎自动等比缩放。不得改尺寸。 | 必须 |
| L2 | 页面内边距 `60px 88px 50px`（引擎默认）。 | 必须 |
| L3 | **70% 规则**：除封面 / 结尾外，所有正文、卡片、表格、图片、结论行的底边 **y ≤ 630px**。下方 30% 只放页脚（出处、说明、页码）。 | 必须 |
| L4 | 结论行（`.kick` / `.insight`）**紧跟正文**，不得沉到页面底部。 | 必须 |
| L5 | 放不下时：先拆页，再改成页内切换（tabs），最后才压缩间距。**不得把正文缩到 15px 以下**。 | 必须 |
| L6 | 表格 ≤ 5 行数据；卡片一行 ≤ 4 张；每张卡正文 ≤ 3 行。 | 应该 |
| L7 | 按 `L` 键显示 70% 安全线，制作和验收时使用。 | 必须 |

## 3. 字号层级（1600 × 900 画布上的 px）

| 层级 | 用途 | 字号 | 字体 |
|---|---|---|---|
| H1 | 封面 / 章节页大标题 | 76–104 | display |
| H2 | 每页标题（≤ 2 行） | **46（固定，不随字号调节放大）** | display |
| Eyebrow | 标题上方的章节路径 | **17（固定）** | body，字距 .14em |
| Kick | 结论行 | 28 | display |
| Body-L | 卡片正文、表格正文 | 18–22 | body |
| Body-S | 次要说明、图注 | 15–16 | body |
| Foot | 页脚出处 / 说明 | 15 / 14 | body |

- 正文默认随“字号调节”放大 112%（`+` / `−` 六档：100%–130%）。H2 与 Eyebrow **不放大**。（必须）
- 内容很满的页面，用 `data-czmax="1.06"` 等限制该页最大放大倍数，保证 70% 规则。（必须）

## 4. 页面结构（每一页）

```html
<section class="slide" id="s-xxx"
  data-title="目录里显示的短标题"
  data-key="本页重点，一句话"
  data-sec="章节名（仅章节首页写）"
  data-sec-time="90"
  data-tier="c">
  <div class="eyebrow">第 N 章 · 第 N 步 · 页面类型</div>
  <h2>标题：一句完整的判断</h2>
  <div class="mdl"><b>模型</b><span><em>模型名</em>：一句通俗解释。</span></div>   <!-- 用到模型时必须有 -->
  <div class="body"> …… </div>
  <div class="kick step">结论一句话，<em>强调部分</em>。</div>
  <div class="foot"><span class="src"><b>出处</b> ……</span><span class="cav">说明：……</span><span class="pageno"></span></div>
  <aside class="notes"><p data-s="0">翻页进入时说的话</p><p data-s="1">第 1 次弹出时说的话</p></aside>
</section>
```

| 编号 | 规则 | 级别 |
|---|---|---|
| P1 | 每页必须有 `id`、`data-title`、`data-key`、`data-sec-time`。 | 必须 |
| P2 | 每页必须有 `aside.notes`；**`.step` 的数量 = `p[data-s]` 的数量 − 1**（第 0 段是翻页进入）。 | 必须 |
| P3 | 页面用到任何模型 / 方法时，标题下必须有 `.mdl` 模型标签：模型名 + 一句白话。 | 必须 |
| P4 | 每页最多 4 个 `.step`（层层追问类可到 5 个）。 | 必须 |
| P5 | 页脚右侧 `.cav`“说明”用于：模拟数据、示意点位、教学解读、未核实数据。不得用醒目的警告框代替。 | 必须 |
| P6 | 标题是“判断句”，不是名词。例：“表格页：需要整体对照的内容，一次性展示”。 | 应该 |

## 5. 展示方式：一次性 / 逐步弹出 / 交互

判断顺序（必须按此顺序判断）：

1. 讲师需要**先提问、学员先想，再给答案**？→ 逐步弹出（问题 → 答案）。
2. 内容有**先后因果，顺序本身就是重点**？→ 逐步弹出（按链条）。
3. 学员需要**动手调参数**或看**同结构的多个案例**？→ 交互组件 / 页内切换。
4. 以上都不是 → **一次性展示**（默认）。

一次性展示的典型内容：封面、目录、全景图、分类表、模型卡、案例清单、课后任务。

## 6. 讲法与写作

| 编号 | 规则 | 级别 |
|---|---|---|
| W1 | 概念用**三段式**：① 一句话（≤ 25 字，不用术语解释术语）② 生活例子 ③ 在本课怎么用。 | 必须 |
| W2 | 模型只深讲一次：第一次出现的页面后放一张**模型卡**（`data-tier="x"`，默认隐藏），之后只放 `.mchip` 回看入口。 | 必须 |
| W3 | 讲稿口语化，用标记：【转场】【抛问题】【指①】【点题】【钩子】【选讲】【时间够再讲】。 | 应该 |
| W4 | 先结论后细节；一句话只说一件事；术语首次出现加中文释义。 | 应该 |
| W5 | 数字、单位、日期、引语**照抄原文**；不得把“可能”写成“一定”。 | 必须 |
| W6 | 没有出处的数据不新增；材料未写明的，写“材料未注明”。 | 必须 |

## 7. 案例与图片

| 编号 | 规则 | 级别 |
|---|---|---|
| C1 | 案例优先选**大众熟知的消费品牌**，只用公开报道可查的事实，页脚写出处与日期。 | 应该 |
| C2 | 每个案例只讲**一个点**；解读写进 `.cav`“说明”。 | 必须 |
| C3 | 不使用品牌标志、吉祥物、官方产品渲染图；品牌只以文字出现。自绘图只画通用物品。 | 必须 |
| C4 | 截图（评论、官网、报告）可直接用，页脚注明来源与日期；截图可点击放大。 | 可以 |
| C5 | 模拟的用户声音、AI 虚拟受访者数据，必须在 `.cav` 写明“模拟 / 仅供参考”。 | 必须 |

## 8. 篇幅分档

| 档位 | 属性 | 含义 |
|---|---|---|
| 精讲 | `data-tier="c"` | 默认显示。主线 + 每步一页核心 + 关键案例。 |
| 完整 | `data-tier="f"` | 按 `V` 切到完整版后显示。补充案例、练习、补充方法。 |
| 选讲 | `data-tier="x"` | 两档都隐藏：模型卡、讲师说明页、备用页。按 `H` 临时显示。 |

## 9. 封面与版权

- 封面必须有：课程 / 系列名（`.org`）、两行主标题（第二行 `<em>` 渐变）、副标题、分享人、日期。
- 引用他人内容时，封面右下角 `.credit` 用小字、低饱和写致谢与版权归属。

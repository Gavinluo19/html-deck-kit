# 01 · 严格规范（Spec）

> 关键词约定：**必须（MUST）** = 不满足即不合格；**应该（SHOULD）** = 默认遵守，有理由可偏离；**可以（MAY）** = 可选。
> 适用对象：人工制作者与 AI（Claude、Codex、WorkBuddy、Trae、飞书 Aily 等）。
> 版本：v2.2（新增：版面三档 L3、用途型动效 §5b、标题与写作规则 W8–W12、画面禁入词、页型标签与分类色）。

---

## 1. 文件与交付

| 编号 | 规则 | 级别 |
|---|---|---|
| F1 | 交付物是**一个独立的 `.html` 文件**，双击即可在 Chrome / Edge / Safari 打开。 | 必须 |
| F2 | 以 `template/deck-template.html` 为母版。只增删 `<section class="slide">`，**不改引擎 CSS 与 JS**（主题 token 除外）。 | 必须 |
| F3 | 图片以 base64 内嵌，单张宽 ≤ 1400px、体积 ≤ 250KB；整个文件 SHOULD ≤ 15MB。 | 必须 |
| F4 | **不内嵌视频**。需要动态效果时，只用 §5b 的 6 种用途型动效（M1–M6），由讲者点击驱动，可被翻页跳过。 | 必须 |
| F5 | 外部资源只允许 Google Fonts；字体栈必须带本地后备字体（见 03-themes.md）。 | 必须 |
| F6 | 需要外部图片文件时，放在与 HTML 同级的 `assets/` 文件夹，并在页面上给出“截图位”占位说明。 | 可以 |
| F7 | 母版左下角的署名 `<a id="tplcredit">Template by Gavin © 2026</a>` **必须保留**，不得删除、改字或放大；它默认暗淡，鼠标移上才加亮，每套主题都适用。 | 必须 |
| F8 | 需要换电脑、断网也显示一致时，用 `tools/embed_fonts.py` 把用到的字子集化后内嵌（只用 SIL OFL 等允许内嵌的字体）。 | 可以 |

## 2. 画布与版面

| 编号 | 规则 | 级别 |
|---|---|---|
| L1 | 画布固定 **1600 × 900**，引擎自动等比缩放。不得改尺寸。 | 必须 |
| L2 | 页面内边距 `60px 88px 50px`（引擎默认）。 | 必须 |
| L3 | **版面三档**：每页用 `data-zone` 声明档位，正文、卡片、表格、图片、结论行的底边不得超过本档底线。<br>① 标准页（默认，不写）：**y ≤ 630px（70%）**，文字为主的页面；<br>② 图解页 `data-zone="75"`：**y ≤ 675px（75%）**，一张主图 + 一句结论；<br>③ 全幅页 `data-zone="full"`：**y ≤ 830px**，只用于泳道图、全景地图、叠图等复杂关系图；**全幅页不超过全稿页数的 20%**。<br>章节页底线 780px；封面 / 结尾不检查。 | 必须 |
| L3a | 全幅页的结论**写进标题或放在上部**；页面下部 25% 只放图例、细节与说明（会议室后排可能看不到）。 | 必须 |
| L4 | 结论行（`.kick` / `.insight`）**紧跟正文**，不得沉到页面底部。 | 必须 |
| L5 | 放不下时：先拆页，再改成页内切换（tabs），再考虑升一档版面，最后才压缩间距。**不得把正文缩到 15px 以下**。 | 必须 |
| L6 | 表格 ≤ 5 行数据；卡片一行 ≤ 4 张；每张卡正文 ≤ 3 行。 | 应该 |
| L7 | 按 `L` 键显示本页档位的安全线（630 / 675 / 830），制作和验收时使用。 | 必须 |
| L8 | 最小字号（按 1600 画布、默认字号 112% 计）：正文 ≥ 18px；标签、脚注 ≥ 13px；**SVG 图内文字 ≥ 14px**（按渲染后大小计）。放不下就拆页，不缩字。 | 必须 |

## 3. 字号层级（1600 × 900 画布上的 px）

| 层级 | 用途 | 字号 | 字体 |
|---|---|---|---|
| H1 | 封面 / 章节页大标题 | 76–104 | display |
| H2 | 每页标题（≤ 2 行） | **46（固定，不随字号调节放大）** | display |
| Eyebrow | 标题上方的章节路径 | **17（固定）** | body，字距 .14em |
| Kick | 结论行 | 28 | display |
| Body-L | 卡片正文、表格正文 | 18–22 | body |
| Body-S | 次要说明、图注 | 15–16 | body |
| Foot | 页脚出处 / 说明 | 15 / 14 | body |

- 正文默认随“字号调节”放大 112%（`+` / `−` 六档：100%–130%）。H2 与 Eyebrow **不放大**。（必须）
- 引擎按页自动适配：所选档位会让某页超出本页底线时，该页自动降档，提示条显示“本页最大 N%”。（v2.1 起）
- `data-czmax` 只在需要**手动**压低某一页上限时使用，**不要给所有页统一加**。（必须）
- SVG 图（`.dgm`）按正文宽度缩放，不随字号放大；图内文字直接按 ≥ 14px 设计。（必须）

## 4. 页面结构（每一页）

```html
<section class="slide" id="s-xxx"
  data-title="目录里显示的短标题"
  data-key="本页重点，一句话"
  data-sec="章节名（仅章节首页写）"
  data-sec-time="90"
  data-tier="c">
  <div class="eyebrow">第 N 章 · 第 N 步 · 页面类型</div>
  <h2>标题：一句完整的判断</h2>
  <div class="mdl"><b>模型</b><span><em>模型名</em>：一句通俗解释。</span></div>   <!-- 用到模型时必须有 -->
  <div class="body"> …… </div>
  <div class="kick step">结论一句话，<em>强调部分</em>。</div>
  <div class="foot"><span class="src"><b>出处</b> ……</span><span class="cav">说明：……</span><span class="pageno"></span></div>
  <aside class="notes"><p data-s="0">翻页进入时说的话</p><p data-s="1">第 1 次弹出时说的话</p></aside>
</section>
```

| 编号 | 规则 | 级别 |
|---|---|---|
| P1 | 每页必须有 `id`、`data-title`、`data-key`、`data-sec-time`。 | 必须 |
| P2 | 每页必须有 `aside.notes`；**步数 = `p[data-s]` 的数量 − 1**（第 0 段是翻页进入）。步数 = `.step` 的个数；用了 `data-step` 时，同号的元素算一步。 | 必须 |
| P3 | 页面用到任何模型 / 方法时，标题下必须有 `.mdl` 模型标签：模型名 + 一句白话。 | 必须 |
| P4 | 每页最多 4 个 `.step`（层层追问类可到 5 个）。 | 必须 |
| P5 | 页脚右侧 `.cav`“说明”用于：模拟数据、示意点位、教学解读、未核实数据。不得用醒目的警告框代替。 | 必须 |
| P6 | 标题是“判断句”，不是名词。例：“表格页：需要整体对照的内容，一次性展示”。 | 应该 |
| P7 | 几个元素要**同时**弹出时，写同一个 `data-step="N"`；一页内要么都写 `data-step`，要么都不写。 | 必须 |
| P8 | 页型标签：`.eyebrow` 里加 `<span class="ptag">案例 · 团餐</span>`；分类页加 `data-cat="case"`（案例）/ `"ex"`（练习）/ `"fw"`（框架）。分类色**只用于页型标签、页码、进度条**，正文仍用主题强调色。 | 应该 |

## 5. 展示方式：一次性 / 逐步弹出 / 交互

判断顺序（必须按此顺序判断）：

1. 讲师需要**先提问、学员先想，再给答案**？→ 逐步弹出（问题 → 答案）。
2. 内容有**先后因果，顺序本身就是重点**？→ 逐步弹出（按链条）。
3. 学员需要**动手调参数**或看**同结构的多个案例**？→ 交互组件 / 页内切换。
4. 以上都不是 → **一次性展示**（默认）。

一次性展示的典型内容：封面、目录、全景图、分类表、模型卡、案例清单、课后任务。

## 5b. 动效（v2.2 新增）

动效只用来说明**关系**：顺序、因果、焦点、变化、前后接续、替换。不做装饰性入场。

| 编号 | 要说明的关系 | 动效 | 写法 | 时长 |
|---|---|---|---|---|
| M1 | 顺序与因果（流程、链条、交接） | 连线按方向画出 | `<path class="mx-draw step" pathLength="1">` | ≤ 900ms |
| M2 | 当前讲哪一个（并列卡、表格行、图中交叉点） | 聚光：当前项保持，其余降到 30% | 容器 `data-mx="focus"`，项目 `data-f="步号"` | ≤ 300ms |
| M3 | 重点在哪（标题、金句、关键词） | 马克笔划过 / 圈 / 下划线 / 划掉 | `<mark class="mx-sweep">`、`.mx-ring`、`.mx-under`、`.mx-strike` | ≤ 600ms |
| M4 | 数量（关键数字） | 数字从 0 滚到终值 | `<b class="fnum" data-count="40">40</b>`（HTML 里先写终值） | ≤ 800ms |
| M5 | 前后接续（定位条 → 章节、全景 → 局部） | 跨页变形 | 相邻两页的对应元素写同一个 `data-morph="名称"` | ≤ 450ms |
| M6 | 替换与纠正（问 → 答、旧 → 新） | 旧内容在第 N 步离场，新内容原位出现 | `.swap` 容器；旧内容 `data-out="N"`，新内容 `.step`；或 `.step` 加 `data-only`（只在本步显示） | ≤ 300ms |

| 编号 | 规则 | 级别 |
|---|---|---|
| MX1 | **先问“这一页要说明什么关系”**，再选 M1–M6；说不出关系就不加动效。 | 必须 |
| MX2 | **每页最多 1 种动效**（M5 跨页变形不计入）。 | 必须 |
| MX3 | 动效只由讲者点击（`.step`）或翻页触发，不自动循环，不定时自动推进。 | 必须 |
| MX4 | 只动 `transform`、`opacity`、`stroke-dashoffset`、`background-size` 四类属性。 | 必须 |
| MX5 | 按 `M` 关闭动效、系统“减少动态效果”、打印、缩略图、演讲者视图预览：一律显示**终态**。制作时要保证终态本身完整可读。 | 必须 |
| MX6 | 动效强调色用主题 `--clay`，计入“强调色五处”（V8）。 | 必须 |
| MX7 | M5 只用于“定位条 → 章节”“全景 → 局部”这类前后接续；不在任意两页之间乱用。 | 应该 |

## 6. 讲法与写作

| 编号 | 规则 | 级别 |
|---|---|---|
| W1 | 概念用**三段式**：① 一句话（≤ 25 字，不用术语解释术语）② 生活例子 ③ 在本课怎么用。 | 必须 |
| W2 | 模型只深讲一次：第一次出现的页面后放一张**模型卡**（`data-tier="x"`，默认隐藏），之后只放 `.mchip` 回看入口。 | 必须 |
| W3 | 讲稿口语化，用标记：【转场】【抛问题】【指①】【点题】【钩子】【选讲】【时间够再讲】。 | 应该 |
| W4 | 先结论后细节；一句话只说一件事；术语首次出现加中文释义。 | 应该 |
| W5 | 数字、单位、日期、引语**照抄原文**；不得把“可能”写成“一定”。 | 必须 |
| W6 | 没有出处的数据不新增；材料未写明的，写“材料未注明”。 | 必须 |
| W8 | **标题写结论**：写观众该带走的那句话，不写话题；**≤ 20 字、≤ 2 行**；不用问号（金句页、提问页除外）。✗“销售数据分析” ✓“七成增长来自老客户复购”。 | 必须 |
| W9 | 同一页并列条目字数接近、句式一致。例：“个人 × AI 扩展能力 / 团队 × AI 放大判断 / 组织 × AI 沉淀资产”。 | 应该 |
| W10 | 对比两栏同一行用同一维度开头：“频率：低 ↔ 频率：高”。 | 应该 |
| W11 | 数字、英文与中文之间加空格：“增长 40%”“AI 工具”。 | 应该 |
| W12 | **画面禁入词**：讲者提示与教学说明只进讲稿，不上画面。例：“问全场”“这里停一下”“挑几条讲”“教学示例”“以下为假设”“本节交付”。检查脚本会报错。 | 必须 |
| W7 | 写给制作者 / AI 的提醒（画面建议、编辑提示、数据口径）写在 `aside.notes` 里的 `<p class="ed">`，只在逐字稿抽屉里显示，不计入讲稿段数，也不会投到大屏。 | 可以 |

## 7. 案例与图片

| 编号 | 规则 | 级别 |
|---|---|---|
| C1 | 案例优先选**大众熟知的消费品牌**，只用公开报道可查的事实，页脚写出处与日期。 | 应该 |
| C2 | 每个案例只讲**一个点**；解读写进 `.cav`“说明”。 | 必须 |
| C3 | 不使用品牌标志、吉祥物、官方产品渲染图；品牌只以文字出现。自绘图只画通用物品。 | 必须 |
| C4 | 截图（评论、官网、报告）可直接用，页脚注明来源与日期；截图可点击放大。 | 可以 |
| C5 | 模拟的用户声音、AI 虚拟受访者数据，必须在 `.cav` 写明“模拟 / 仅供参考”。 | 必须 |
| C6 | 对外版本不出现客户真名（改为“一家团餐公司”）；截图中的姓名、手机号、水印先打码。 | 必须 |
| C7 | 同类案例用**相同页数、相同版式**讲完，方便观众横向比较。 | 应该 |

## 7b. 视觉克制（v2.0 新增）

| 编号 | 规则 | 级别 |
|---|---|---|
| V1 | 标题里**最多一个**重点短语用 `<mark>` 标出（2–6 个字）；正文不用 `<mark>`。 | 应该 |
| V2 | 不用大面积实心色块（尤其黑色、深色）做卡片底；改为纸白卡片 + 细线，强调色只留在重点词、细边或一个数字上。 | 必须 |
| V3 | 图标只用线性 SVG（`.ic`，描边跟随文字颜色），不用 emoji、不用彩色图标；同一页图标风格一致。图标库见 `07-icons.md`。 | 必须 |
| V4 | 表头不铺底色：细线 + 灰字即可。 | 应该 |
| V5 | 截图编号 ≤ 5 个，截图上只放编号，解释写在旁边 `.pinlist`；手机截图 ≤ 3 张；引线批注 ≤ 2 条。 | 必须 |
| V6 | 内容少的页面由引擎自动下移居中（只在 70% 区域内移动）；某页不需要时加 `data-balance="0"`。 | 可以 |
| V7 | 章节较多（≥ 5 步）时，每章开头放一页章节定位页（T13），让听众知道“讲到第几步”。 | 应该 |
| V8 | 强调色只用于五处：标题马克笔、结论行、重点卡片描边、最关键的一个数据、动效高亮。小标题、表头、坐标轴、图标、编号用墨色或灰色。 | 必须 |
| V9 | 金句页不超过全稿页数的 8%；行尾标点由引擎自动悬挂；居中版式加 `.slide.stmt.c`。 | 应该 |
| V10 | 自绘 SVG 只写 `style="fill:var(--token)"`，不写十六进制颜色，换主题时图要跟着变。 | 必须 |
| V11 | 对外放映按 `K`：隐藏眉标、页码、`.cav` 说明与改稿入口，页型标签保留。 | 可以 |

## 8. 篇幅分档

| 档位 | 属性 | 含义 |
|---|---|---|
| 精讲 | `data-tier="c"` | 默认显示。主线 + 每步一页核心 + 关键案例。 |
| 完整 | `data-tier="f"` | 按 `V` 切到完整版后显示。补充案例、练习、补充方法。 |
| 选讲 | `data-tier="x"` | 两档都隐藏：模型卡、讲师说明页、备用页。按 `H` 临时显示。 |

## 9. 封面与版权

- 封面必须有：课程 / 系列名（`.org`）、两行主标题（第二行 `<em>` 渐变）、副标题、分享人、日期。
- 引用他人内容时，封面右下角 `.credit` 用小字、低饱和写致谢与版权归属。

# 05 · 交付检查清单（逐项打勾）

## A. 结构
- [ ] 以 `template/deck-template.html` 为母版，引擎 CSS / JS 未改动
- [ ] 每页有 `id`、`data-title`、`data-key`、`data-sec-time`，章节首页有 `data-sec`
- [ ] 每页有 `aside.notes`，步数 = 讲稿段数 − 1（`data-step` 同号算一步）
- [ ] 每页声明了版面档位：默认标准页；图解页 `data-zone="75"`；全幅页 `data-zone="full"` 且不超过全稿 20%
- [ ] 用到模型的页面都有 `.mdl` 模型标签；模型卡只出现一次，后续用 `.mchip`
- [ ] 篇幅档位 `data-tier` 已设置（c / f / x）
- [ ] 有“总—分—总”全课地图页，步骤卡下方列出所用模型
- [ ] 左下角署名 `#tplcredit`（Template by Gavin © 2026）仍在，未改字、未放大

## B. 版面
- [ ] 按 L 检查：所有正文与结论行在本页档位底线以上（630 / 675 / 830）
- [ ] 全幅页的结论写在标题或上部，底部只放图例与细节
- [ ] 结论行紧跟正文，不沉底
- [ ] 正文 ≥ 18px，标签与脚注 ≥ 13px，SVG 图内文字 ≥ 14px；表格 ≤ 5 行
- [ ] 字号放到 130% 时检查一遍（引擎自动降档；只在必要时手动加 `data-czmax`）

## C. 内容
- [ ] 标题是结论、≤ 20 字、≤ 2 行；同页并列条目对仗；数字与中文之间有空格
- [ ] 画面没有讲者提示与教学说明（问全场、这里停一下、教学示例……）；对外版本没有客户真名，截图已打码
- [ ] 同类案例页数与版式一致
- [ ] 强调色只出现在五处：马克笔、结论行、重点描边、关键数据、动效高亮；自绘 SVG 只用 `var(--token)`
- [ ] 动效：每页最多 1 种，且说得出它说明的关系；按 M 关闭后终态完整可读
- [ ] 金句页 ≤ 全稿 8%
- [ ] 概念都按三段式：一句话 / 生活例子 / 怎么用
- [ ] 标题重点词 `<mark>` 每页最多一个；没有大面积实心深色块；图标都是线性 `.ic`
- [ ] 截图编号 ≤ 5、手机截图 ≤ 3、引线 ≤ 2；写给制作者的提醒放在 `p.ed`，没有出现在页面上
- [ ] 数字、日期、引语照抄原文，页脚有出处与日期
- [ ] 模拟数据、示意点位、教学解读都在 `.cav` 写了“说明”
- [ ] 案例为大众熟知品牌，只用公开事实；无品牌标志与官方产品图
- [ ] 封面有致谢与版权（引用他人内容时）

## D. 交付
- [ ] 单个 HTML 文件，图片 base64 内嵌，无视频
- [ ] Chrome 与 Safari 各翻一遍：精讲版、完整版各一遍
- [ ] T 切换 7 套主题，封面与正文都可读
- [ ] 按 K（对外放映）、M（动效开关）各看一遍；Ctrl/⌘ + P 存为 PDF，页数 = 放映页数
- [ ] 按 O 打开筛片台、按 E 写一条测试意见，确认都能保存；交付前在“修改汇总”里清空测试意见
- [ ] 运行 `python3 tools/check_layout.py 你的文件.html` 与 `--zoom 1.3`，错误为 0；警告逐条处理或说明理由

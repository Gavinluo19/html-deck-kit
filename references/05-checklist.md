# 05 · 交付检查清单（逐项打勾）

## A. 结构
- [ ] 以 `template/deck-template.html` 为母版，引擎 CSS / JS 未改动
- [ ] 每页有 `id`、`data-title`、`data-key`、`data-sec-time`，章节首页有 `data-sec`
- [ ] 每页有 `aside.notes`，`.step` 数 = 讲稿段数 − 1
- [ ] 用到模型的页面都有 `.mdl` 模型标签；模型卡只出现一次，后续用 `.mchip`
- [ ] 篇幅档位 `data-tier` 已设置（c / f / x）
- [ ] 有“总—分—总”全课地图页，步骤卡下方列出所用模型

## B. 版面
- [ ] 按 L 检查：所有正文与结论行在 70% 线（y = 630px）以上
- [ ] 结论行紧跟正文，不沉底
- [ ] 正文 ≥ 18px，次要文字 ≥ 15px；表格 ≤ 5 行
- [ ] 字号放到 130% 时，内容很满的页面已用 `data-czmax` 限制

## C. 内容
- [ ] 概念都按三段式：一句话 / 生活例子 / 怎么用
- [ ] 数字、日期、引语照抄原文，页脚有出处与日期
- [ ] 模拟数据、示意点位、教学解读都在 `.cav` 写了“说明”
- [ ] 案例为大众熟知品牌，只用公开事实；无品牌标志与官方产品图
- [ ] 封面有致谢与版权（引用他人内容时）

## D. 交付
- [ ] 单个 HTML 文件，图片 base64 内嵌，无视频
- [ ] Chrome 与 Safari 各翻一遍：精讲版、完整版各一遍
- [ ] T 切换 6 套主题，封面与正文都可读
- [ ] 运行 `python3 tools/check_layout.py 你的文件.html`，无 `OVER` 输出

# 04 · 演示操作、讲稿与调整方式

## 1. 快捷键（引擎内置）

| 按键 | 作用 |
|---|---|
| → / 空格 / Enter / 点击右侧 | 下一步（先弹出本页 `.step`，弹完再翻页） |
| ← / Backspace / 点击左侧 30% | 上一步 |
| G 或 O | 打开目录抽屉（按章节折叠，可点页跳转、可设“隐藏”） |
| 数字键 | 打开目录并输入页码跳转 |
| S | 右侧逐字稿抽屉（本页重点 + 每一步讲稿 + 下一页预告） |
| N | 底部讲稿条 |
| P | 演讲者视图（右侧显示“现在说 / 下一步”与计时） |
| F | 全屏 |
| H | 临时显示全部隐藏页 |
| Home / End | 第一页 / 最后一页 |
| **T** | 切换主题（6 套，循环） |
| **V** | 切换篇幅：精讲版 ↔ 完整版 |
| **+ / −** | 正文字号（100%–130% 六档，标题与眉标不变） |
| **L** | 显示 / 隐藏 70% 安全线 |
| **B** | 在模型卡上按 B 返回原页 |
| Esc | 关闭抽屉 / 放大图 |

以上设置（主题、篇幅、字号、手动隐藏）保存在本机浏览器，下次打开自动恢复；目录抽屉里“恢复默认”可清除隐藏设置。

## 2. 讲稿规则

- 每页 `aside.notes` 内按顺序写 `p[data-s="0"]`、`p[data-s="1"]`……
- `data-s="0"` 是翻页进入时说的话；`data-s="n"` 对应第 n 个 `.step` 弹出时说的话。
- 讲稿是口语，不是页面文字的复述：补充例子、过渡句、提问。
- 概念页讲稿分两段：必讲（30 秒内）+ 【时间够再讲】。
- 目录抽屉显示每章预计时长，来源于 `data-sec-time`（秒）。

## 3. 交互组件的实现约束

- 组件内的滑块、按钮、圆点**必须 `stopPropagation`**，否则点击会同时翻页（模板已处理）。
- 交互页的结论行不加 `.step`，避免与交互冲突。
- 四象限、计算器的预置数值没有出处时，页脚 `.cav` 写“点位为教学示意”或“现场演示”。

## 4. 给讲师的三种调整方式

1. **讲多讲少**：按 V 切精讲 / 完整；在目录抽屉里给单页点“隐藏”。
2. **看不清**：按 + 放大正文；内容很满的页面会自动停在安全上限。
3. **换风格**：按 T 换主题；或把 `<html data-theme="…">` 改成想要的主题作为默认。

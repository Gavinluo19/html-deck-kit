# 04 · 演示操作、讲稿与调整方式

## 1. 快捷键（引擎内置）

| 按键 | 作用 |
|---|---|
| → / 空格 / Enter / 点击右侧 | 下一步（先弹出本页 `.step`，弹完再翻页） |
| ← / Backspace / 点击左侧 30% | 上一步 |
| G | 打开目录抽屉（按章节折叠，可点页跳转、可设“隐藏”） |
| **O** | **筛片台**（v2.0）：全屏缩略图，按章节分组；拖动调整放映顺序、单页或整章隐藏、复制清单 |
| **E** | **修改本页**（v2.0）：给当前页写修改意见；“修改汇总”可一次复制全部意见交给 AI |
| 数字键 | 打开目录并输入页码跳转 |
| S | 右侧逐字稿抽屉（本页重点 + 每一步讲稿 + 下一页预告） |
| N | 底部讲稿条 |
| P | 演讲者视图（右侧显示“现在说 / 下一步”、**下一页缩略图**与计时，可“计时归零”） |
| F | 全屏 |
| H | 临时显示全部隐藏页 |
| Home / End | 第一页 / 最后一页 |
| **T** | 切换主题（6 套，循环） |
| **V** | 切换篇幅：精讲版 ↔ 完整版 |
| **+ / −** | 正文字号（100%–130% 六档，标题与眉标不变） |
| **L** | 显示 / 隐藏 70% 安全线 |
| **B** | 在模型卡上按 B 返回原页 |
| Esc | 关闭抽屉 / 放大图 |

逐字稿抽屉右上角 **A− / A+** 调讲稿字号（不影响页面）。网址后加 `#页面id`（如 `#s-ov`）可直接打开某一页。

以上设置（主题、篇幅、字号、手动隐藏、放映顺序、修改意见）保存在本机浏览器，下次打开自动恢复；目录抽屉里“恢复默认”可清除隐藏设置。

## 2. 讲稿规则

- 每页 `aside.notes` 内按顺序写 `p[data-s="0"]`、`p[data-s="1"]`……
- `data-s="0"` 是翻页进入时说的话；`data-s="n"` 对应第 n 个 `.step` 弹出时说的话。
- 讲稿是口语，不是页面文字的复述：补充例子、过渡句、提问。
- 概念页讲稿分两段：必讲（30 秒内）+ 【时间够再讲】。
- 目录抽屉显示每章预计时长，来源于 `data-sec-time`（秒）。

## 2b. 修改闭环（v2.0）

1. 讲师或同事打开 HTML，逐页翻看，觉得要改的页按 **E** 写一句话意见（例如“标题再短一点”“这张图换成流程”）。
2. 写完点“修改汇总” → “复制全部”，得到按页排好的文字：`【第 N 页 · 页面id】标题` + 意见。
3. 把这段文字连同 HTML 一起交给 AI：“按修改汇总逐页修改，页面 id 不变，改完运行 check_layout”。
4. 在 claude.ai 上以 Artifact 发布时，如果页面开通了共享数据库，意见会同步保存，Claude 可以直接读取；否则只存在本机浏览器。

## 2c. 筛片台（v2.0）

- 适合“同一份完整稿，按场合挑页”：拖动缩略图改顺序；点“保留 / 已隐藏”切换单页；“隐藏本章”整章跳过。
- “复制清单”得到放映顺序与隐藏页列表，可交给 AI 生成一个只含这些页的新文件。
- 顺序按页面 `id` 保存，所以**页面 id 一旦确定不要改**。“恢复原顺序”可撤销。

## 3. 交互组件的实现约束

- 组件内的滑块、按钮、圆点**必须 `stopPropagation`**，否则点击会同时翻页（模板已处理）。
- 交互页的结论行不加 `.step`，避免与交互冲突。
- 四象限、计算器的预置数值没有出处时，页脚 `.cav` 写“点位为教学示意”或“现场演示”。

## 4. 给讲师的三种调整方式

1. **讲多讲少**：按 V 切精讲 / 完整；在目录抽屉里给单页点“隐藏”；或按 O 打开筛片台，拖动排序、整章隐藏。
2. **看不清**：按 + 放大正文；内容很满的页面会自动停在安全上限。
3. **换风格**：按 T 换主题；或把 `<html data-theme="…">` 改成想要的主题作为默认。

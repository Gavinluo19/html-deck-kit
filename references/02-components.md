**选模板的顺序**：先问“这页要说明什么关系”——先后与交接 → T20 / T17；两方体验 → T21；体验与流程的对照 → T22；写法 → T19；自测 → T18；练习 → T23。复杂关系图优先画成图，不写成文字框堆叠。

V2.1 实战稿中另有：截图证据页（`.shots` + `.th3` 主题卡）、页内切换（tabs）、全链路演示（`.demo8`）、虚拟访谈页（`.webshot` / 官网截图）。需要时按同样结构添加。

## 3. 颜色使用规则

- 组件里**只写 `var(--token)`**，不写十六进制色值（自绘 SVG 也用 `style="fill:var(--clay)"`）。
- 强调色 `--clay` 只用于五处（V8）：标题马克笔、结论行、重点描边、最关键的一个数据、动效高亮。
- 分类色（`data-cat`）只用于页型标签、页码、进度条，不进正文。
- 次强调 `--sky` 用于“模型 / AI / 信息类”元素；`--warn` 只用于风险、负面。

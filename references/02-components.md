# 02 · 页面模板与组件

所有模板在 `template/deck-template.html` 中都有一页可复制的示例（按 `id` 查找）。
制作时：**复制示例页 → 改内容 → 保持结构与类名不变**。

## 2. 组件清单

| 类名 | 作用 | 要点 |
|---|---|---|
| `.eyebrow` | 标题上方的章节路径 | “第 N 章 · 第 N 步 · 页面类型” |
| `.mdl` | 模型标签 | `<b>模型</b><span><em>名</em>：一句白话</span>`；用到模型的页必须有 |
| `.mchip` | 右上角“模型卡 ▸”入口 | `data-to="模型卡 id"`；模型卡里放 `.mback` 返回，或按 B |
| `.tri3 > .r` | 三段式行 | `.k` 小标签 + `p` 正文 |
| `.box` / `.box.hl` / `.box.blue` | 内容框 / 强调框 / 次强调框 | `.k` 为框内小标题 |
| `.ex > .e(.k2/.b/.w)` | 编号要点卡 | `.mk` 圆形编号 |
| `.tb.big(.roomy)` | 表格 | 首行 `th`；`.sub` 次级说明 |
| `.tri` | 三步箭头流 | `.box` + `.arr` 交替 |
| `.voice` | 用户原话条 | `small` 写来源 |
| `.case` / `.pic` / `.crow` / `.cr` | 案例卡 | `.pic` 内放图片或自绘 SVG（颜色用 `var(--token)`） |
| `.flow3 > .bx` | 声音 → 洞察 → 方向 | `.bx.hl` 为结论格 |
| `.zrow` / `.zlab` / `.zbox` / `.zai` | 总分总行 | `.zlab.k` 分；`.zlab.ai` AI 行 |
| `.ov9 > .ovc` / `.ovm` | 步骤卡 / 模型虚线框 | `.ovc` 可加 `data-goid` 点击跳转；`.ovm span.k` 标重点模型 |
| `.lv5 > .lvc` | 五级卡 | `.r` 会说 / 会做；`.ex` 真实例子 |
| `.calc` / `.sl` / `.res` | 计算器 | `input[data-k]`；结果 `#painNum` |
| `.qd` / `.pt2` / `.qinfo` | 四象限 | `.pt2` 写 `data-n / data-t / data-c / data-d` |
| `.shots > .shot` | 截图组 | 点击放大；`figcaption` 写来源 |
| `.kick` / `.insight` | 结论行 | `<em>` 为强调色；最多两行 |
| `.note > .tag` | 小注释 | 如“AI 能帮”“产出” |
| `.cav` | 页底说明 | 只放在 `.foot` 内，位于页码左侧 |
| `.credit` | 封面致谢与版权 | 小字、低饱和、右下角 |

## 3. 颜色使用规则

- 组件里**只写 `var(--token)`**，不写十六进制色值（自绘 SVG 也用 `style="fill:var(--clay)"`）。
- 强调色 `--clay` 每页最多用于：1 个标题强调 + 1 个结论强调 + 1 处数据。
- 次强调 `--sky` 用于“模型 / AI / 信息类”元素；`--warn` 只用于风险、负面。
